How to resume a failed download

The Wi-Fi drops at 95% of a 6 GB file and the browser says “Failed”. Often you can still continue from where it stopped — if you don’t click the wrong button. Here’s how in Chrome, Edge and Firefox, why some downloads can’t be resumed, and how to make sure it never costs you the whole file again.

{{byline}}

Short answer

  1. Open the browser’s download list: Ctrl+J in Chrome and Edge, Ctrl+Shift+Y in Firefox (⌘ on a Mac).
  2. Click Resume on the failed download. Don’t cancel or remove it first — that deletes the part already downloaded.
  3. If there’s only Retry, the server can’t continue a download and it will start from zero. A download manager can’t change that, but it can stop it happening for every other file.

Resume in Chrome and Edge

  1. Press Ctrl+J (Mac: ⌘+Shift+J) or open chrome://downloads — in Edge, edge://downloads.
  2. Find the download marked as failed or interrupted.
  3. Click Resume. The download continues from the last byte saved, if the server allows it.

Chrome and Edge also try to resume on their own after short network drops. If a download has been sitting at “Failed – Network error” for a while, a manual Resume after your connection is back usually works.

Resume in Firefox

  1. Open the downloads list with Ctrl+Shift+Y (Mac: ⌘+Shift+Y), or the arrow icon in the toolbar.
  2. Click the retry arrow next to the failed download, or right-click it and choose Resume or Retry.

Firefox continues from the partly downloaded file when the server supports it; otherwise it starts again.

Why a download can’t be resumed

To continue, the browser asks the server for “the file from byte 5,812,000 onwards” (an HTTP range request). That works only when all of these are true:

  • The server supports range requests. Most file servers do. Some dynamically generated downloads (exports, on-the-fly zips) don’t.
  • The link still works. Cloud storage and many download sites give out links that expire after minutes or hours. After that, resuming fails with “Forbidden” — open the download page again to get a fresh link.
  • The partial file is still there. Cancelling or removing the download from the list deletes it, and so do some cleanup tools.
  • The file on the server hasn’t changed. If it was replaced with a new version, the old part is useless and the download must start over.

What the error messages mean

MessageWhat happened and what to do
Failed – Network error / Network issueThe connection dropped: Wi-Fi, sleep, a VPN reconnecting. Fix the connection, then click Resume.
Failed – ForbiddenThe server refused the request, usually because the link expired or needs you to be signed in. Start the download again from the website.
Failed – No fileThe file is gone from the server, or the link was wrong.
Failed – Disk fullNot enough space. Free some up or choose another drive, then resume.
Failed – Virus detected / BlockedYour antivirus or the browser blocked the file. Don’t override this unless you trust the source completely.

.crdownload and .part files

While a file downloads, Chrome and Edge store it as name.crdownload, and Firefox as name.part. They hold the bytes received so far.

  • As long as the download is still in the browser’s list, use Resume there.
  • Renaming the file doesn’t complete it. An incomplete video may partly play; an incomplete zip or installer won’t open.
  • Once the download has been removed from the list, browsers can’t pick up the partial file again. You’ll have to download it again.

Never start a big download over again

Browsers do resume, but they give up easily, and closing the browser or a crash can lose the progress. For large files, a download manager is built for exactly this. Prism, a free and open-source download manager for Windows, macOS and Linux:

  • Saves progress continuously, only after the data is safely on disk, so a crash, a reboot or a power cut costs seconds, not gigabytes.
  • Checks the file hasn’t changed on the server before continuing (size, ETag and Last-Modified), so you never end up with a corrupted mix of two versions.
  • Retries dropped connections by itself, and in our tests finished a download from a server that randomly cut connections where aria2 gave up.
  • Keeps the computer awake while it downloads, so the PC doesn’t fall asleep halfway through.

Its browser extension hands downloads from Chrome, Edge, Brave, Opera, Vivaldi and Firefox to Prism with one click.

One limit applies to every tool: if the server doesn’t support resuming, or the link has expired, nothing can continue the old download. A download manager just makes sure that it rarely has to.

FAQ

Failed downloads, answered.

Can I resume a download in Chrome after it failed?

Usually yes. Open chrome://downloads and click Resume on the failed download. It works if the server supports range requests, the link hasn’t expired and the partial file still exists. If Chrome only offers Retry, the download starts from the beginning.

Why does my download keep failing with a network error?

The connection drops for a moment: weak Wi-Fi, the computer going to sleep, a VPN reconnecting, or an overloaded server closing the connection. Use a cable if you can, stop the PC from sleeping, and use a download manager that reconnects and continues by itself.

How do I open a .crdownload file?

You don’t: it’s an unfinished download. Resume it from chrome://downloads while it’s still listed there. Renaming it won’t complete the file.

Can a download manager resume a download that Chrome started?

Not from Chrome’s partial file. Start the download in the download manager instead — with Prism’s extension that happens automatically when you click the link — and from then on it can always be resumed.

Why does “Resume” start from 0%?

The server doesn’t support continuing a download, or the file on the server changed, so the old part can’t be reused. Every browser and download manager has to start over in that case.

Chrome downloads slow? Here’s what actually helps

Chrome itself is rarely the slow part. It downloads every file over a single connection, so it’s only as fast as that one connection to the server — and many servers deliberately keep each connection slow. Here’s how to tell what’s going on, and the fixes that work in Chrome, Edge, Brave and other Chromium browsers.

{{byline}}

Short answer

  1. Download the same file in another browser. If it’s just as slow, Chrome isn’t the problem — the server or your network is.
  2. Turn off extensions that touch downloads or traffic (VPNs, proxies, other download managers) and try again.
  3. If big files from one site are always slow, that server limits each connection. A download manager that uses several connections fixes exactly that.

Why Chrome downloads can be slow

  • One connection per file. Chrome fetches a file over one connection. File hosts, mirrors and some cloud services cap the speed of each connection, so one connection can’t reach your line speed.
  • The network. Weak Wi-Fi, other devices streaming or updating, or a VPN.
  • Something between Chrome and the file: an extension that inspects or reroutes traffic, a proxy, or a cloud-synced download folder.

Clearing the cache, cookies or history doesn’t change download speed, so you can skip that common advice.

1. Test: is it Chrome, the network or the server?

Run a speed test, then download the same file in Edge or Firefox. Remember that speed tests show megabits and Chrome shows megabytes: 100 Mbps is about 12 MB/s.

  • Both browsers slow, speed test slow: it’s your connection. See how to download faster on a PC.
  • Both browsers slow, speed test fast: it’s the server. Try another mirror or more connections (fix 6).
  • Only Chrome slow: it’s an extension, a setting or the Chrome profile. Fixes 2–4.

2. Rule out extensions

The quickest test is an Incognito window (Ctrl+Shift+N), where extensions are off unless you allowed them. If the download is fast there, open chrome://extensions and turn extensions off one by one. The usual suspects are VPN and proxy extensions, “download accelerator” extensions, and the browser extension of a download manager you no longer use (for example IDM Integration Module), which keeps taking over downloads for as long as it’s turned on.

3. Check where Chrome saves files

Open chrome://settings/downloads. If the location is a network drive, a USB stick or a folder that OneDrive, Dropbox or Google Drive syncs, the drive or the sync app can slow the download down. Pick a local folder on your internal drive, and move the file afterwards.

4. Check the VPN or proxy

A VPN app or extension sends the download through its own server, sometimes on another continent. Switch to a server near you, or pause the VPN for a trusted download and compare. Also check Settings → System → Open your computer’s proxy settings for a proxy you didn’t set up.

5. Try Chrome’s parallel downloading flag

Chrome and Edge have an experimental setting that splits a download into a few parts. If your version still offers it:

  1. Open chrome://flags/#enable-parallel-downloading (in Edge: edge://flags/#enable-parallel-downloading).
  2. Set Parallel downloading to Enabled and click Relaunch.

Keep your expectations realistic. Flags are experiments that can change or disappear, the browser uses only a few parts, and as a browser engineer explains in detail, parallel connections only help when the server throttles each connection or the network is unstable. On a fast server, your line is already the limit.

6. Hand big downloads to a download manager

For large files from servers that limit each connection, a download manager is the reliable fix. It downloads one file over many connections, keeps every connection busy until the end, and resumes after a dropped connection instead of starting over.

Prism is free and open source, for Windows, macOS and Linux. Add the Prism extension to Chrome, Edge, Brave, Opera or Vivaldi, and clicking a download link opens Prism instead of Chrome’s own download bar. Hold Alt while clicking to let Chrome download a file as usual.

In our tests, a 1 GiB file from a server that caps each connection downloaded about 15× faster this way (benchmarks). On a server without limits, every tool reaches the same speed: your line’s.

7. Update Chrome and restart it

Open chrome://settings/help; Chrome checks for an update and asks you to relaunch. A browser that has been open for weeks with hundreds of tabs can also slow down in general — a restart is a cheap test.

Stuck on “Starting…” or at 100%

  • “Starting…” for a long time: usually the server preparing the file (common for generated zips and exports), or a slow redirect chain. Waiting or retrying is all you can do in the browser.
  • A pause at 100%: Chrome and your antivirus check the finished file. Large archives take a few seconds longer. If a file is blocked, Chrome says so in chrome://downloads.
  • “Failed – Network error”: see how to resume a failed download.

FAQ

Slow Chrome downloads, answered.

Why are my Chrome downloads so slow when my internet is fast?

Chrome downloads each file over one connection, and many servers limit how fast one connection may go. Speed tests use many connections to nearby servers, so they look much faster. Extensions, VPNs and a cloud-synced download folder can also slow Chrome down.

Does the parallel downloading flag make Chrome faster?

Sometimes, on servers that throttle each connection. It is an experimental flag, it splits a file into only a few parts, and it doesn’t help when the server or your line is already the limit.

Is Edge or Firefox faster than Chrome for downloads?

Not meaningfully. They all download a file over a single connection by default. If one browser is much faster than another on the same file, look for an extension or a proxy setting in the slow one.

How do I make Chrome download faster?

Fix the bottleneck: use a cable or 5 GHz Wi-Fi, pause other downloads and the VPN, save to a local drive, and turn off extensions that reroute traffic. For big files from slow servers, send the download to a download manager that uses several connections, such as Prism.

Can I still use Chrome’s own downloads with a download manager installed?

Yes. With Prism’s extension, hold Alt while clicking a link to let Chrome download it, or click the extension’s icon and choose Pause capture.

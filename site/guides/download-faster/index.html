How to download faster on a PC

Most “speed up your internet” tips don’t touch the real problem. A slow download has exactly one bottleneck — your line, your Wi-Fi, something else using the connection, or the server. Find which one it is, and the fix is usually two minutes away.

By Jan Sechovec, the developer of Prism · Updated 27 November 2026

Short answer

  1. Run a speed test and divide the result by 8: a 100 Mbps plan downloads at about 12 MB/s, not 100.
  2. If the download is far below that, plug in a cable or move to 5 GHz Wi-Fi, and pause whatever else is downloading.
  3. If only some sites are slow, the server is limiting you. Pick a closer mirror, or use a download manager that opens several connections at once.

Find the bottleneck first

Open a speed test (Speedtest by Ookla, fast.com or your provider’s own) on the same PC, then start your download and compare. Three outcomes, three different fixes:

  • The speed test is slow too. The problem is your connection at home: Wi-Fi, other devices, the router or the plan itself. Fixes 2–5 and 9.
  • The speed test is fast, every download is slow. Something on this PC: a VPN, background apps, a slow target drive. Fixes 3–5 and 8.
  • The speed test is fast, only one site is slow. That server is the bottleneck. It may be far away, busy, or limiting how fast each connection can go. Fixes 6 and 7.

1. Mbps vs MB/s: check you’re not already at full speed

Internet plans and speed tests are measured in megabits per second (Mbps). Browsers and download managers show megabytes per second (MB/s). One byte is eight bits, so divide by 8:

Your planBest realistic download speed
50 Mbpsabout 6 MB/s
100 Mbpsabout 12 MB/s
300 Mbpsabout 35 MB/s
1 Gbpsabout 110–117 MB/s

A few percent go to protocol overhead, so a 100 Mbps line showing 11.5 MB/s is already maxed out. Nothing on the PC can make it faster — only a faster plan can.

2. Use a cable, or the right Wi-Fi band

Wi-Fi is the most common reason a fast plan gives slow downloads. Walls, distance and neighbours’ networks all cut its speed, and it gets worse the further you are from the router.

  • An Ethernet cable removes the problem completely. For a big download, it’s worth plugging in even a laptop.
  • On Wi-Fi, use 5 GHz or 6 GHz instead of 2.4 GHz when you’re in the same room or the next one. Many routers show the bands as two network names; others pick automatically.
  • Move closer, or move the router out of a cupboard. A mesh system or a cabled access point helps in large homes.

3. Stop whatever else is downloading

Every device and app on your network shares the same line. Game launchers, cloud sync (OneDrive, Google Drive, Dropbox, iCloud), backups and 4K streams on the TV can each take most of it.

On Windows, open Task Manager (Ctrl+Shift+Esc) and sort the Processes tab by the Network column to see what is using the connection right now. On a Mac, open Activity Monitor → Network. Pause the culprits until your download is done.

4. Limit Windows Update’s background downloads

Windows downloads updates in the background, and by default it can also share them with other PCs. If downloads are slow right after Patch Tuesday, this is often why. In Windows 11:

  1. Open Settings → Windows Update → Advanced options → Delivery Optimization.
  2. Turn off Allow downloads from other devices if you don’t need it.
  3. Under Advanced options, set a limit for how much bandwidth background updates may use.

5. Pause the VPN or pick a closer server

A VPN sends everything through its own server, often in another country, and encrypts it on the way. That usually costs speed. For a large download from a site you trust, try a VPN server close to you, or pause the VPN and compare. The same goes for proxies and “data saver” features.

6. Download from a closer mirror

Linux distributions, open-source projects and many game and driver sites publish the same file on several servers (“mirrors”). A mirror in your country is often several times faster than the default one on another continent. Look for a Mirrors or Other download locations link next to the download button.

7. Use more than one connection

A browser downloads a file over a single connection. Many servers — file hosts, mirrors, some cloud storage — cap the speed per connection, so one connection never reaches your line speed no matter how fast it is.

A download manager splits the file into parts and fetches them over several connections at once. In our tests on a server that caps each connection, a 1 GiB file came down at 4 MiB/s over one connection and 61 MiB/s over many — about 15× faster (benchmarks).

Prism is a free, open-source download manager that does this on Windows, macOS and Linux: 8 connections by default, up to 32, and it notices when a server allows fewer and remembers that per site. Its browser extension sends downloads from Chrome, Edge or Firefox to it automatically.

The honest part: if the server doesn’t limit connections, your line is the limit. On a normal 200 Mbps line, Prism, aria2 and curl all landed at the same ~25 MiB/s in our tests. More connections help with slow servers and unstable networks, not with a slow plan.

8. Save to a fast, local drive

At gigabit speeds, the drive can become the bottleneck. Saving to an old USB stick, a network share or a folder that a cloud app syncs while you download slows things down. Download to an internal SSD first, then move the file. Antivirus scanning can also pause a download at the very end; that’s normal and takes seconds, not minutes.

9. Restart the router and update the network driver

Routers that have run for months sometimes slow down; a restart (unplug for 30 seconds) clears that. On Windows, check Device Manager → Network adapters or your PC maker’s support page for a newer Wi-Fi or Ethernet driver, especially on a new or freshly reinstalled PC. If speeds are still far below your plan on a cable, call your provider with the speed test results.

What doesn’t work

  • “Internet booster” and RAM-cleaner apps. They can’t make your line or a server any faster.
  • Registry and TCP tweaks. Modern Windows, macOS and Linux tune TCP automatically. Old tweaks from 2008 guides are more likely to hurt.
  • Changing DNS to speed up a download. DNS only turns a name into an address before the download starts; it doesn’t change how fast the file arrives.
  • Closing browser tabs. Idle tabs use almost no bandwidth. A tab that is streaming video does — pause that one.

FAQ

Download speed, answered.

Why is my download speed slower than my internet speed?

Often it isn’t: plans are sold in megabits per second and downloads are shown in megabytes per second, so 100 Mbps means about 12 MB/s. If it really is slower, the usual causes are Wi-Fi, other apps using the line, a VPN, or a server that limits the speed of each connection.

Does a download manager really make downloads faster?

Only when the server is the bottleneck. On servers that cap each connection, downloading over several connections at once can be many times faster — 15× in our test. When the server doesn’t limit you, your line is the limit for every tool. A download manager still helps by resuming failed downloads instead of starting over.

How many connections should I use for one download?

Around 8 is a good default. Go up to 16 or 32 for servers that are clearly slow per connection. Some servers allow only a few connections; a good download manager notices that and uses what the server allows instead of failing.

Is Ethernet really faster than Wi-Fi?

Usually, yes, and it is far more stable. Wi-Fi speed drops with distance, walls and interference from nearby networks. On fast plans (500 Mbps and up), a cable is often the only way to get the full speed.

Why does a download start fast and then slow down?

Some servers allow a fast burst and then throttle. It can also be another app starting its own download, Wi-Fi conditions changing, or the drive filling its fast cache. Pausing and resuming will not help with a throttling server; more connections or another mirror will.

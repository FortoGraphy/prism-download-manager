How to open and download magnet links

A magnet link isn’t a file — it’s a fingerprint of one. To download it you need a BitTorrent client, a free app that finds the people sharing the file and fetches it from them. Here’s how it works on Windows, macOS and Linux, without uTorrent and without ads.

By Jan Sechovec, the developer of Prism · Updated 27 November 2026

Short answer

  1. Install a free BitTorrent client — for example Prism, which also handles normal downloads, or qBittorrent.
  2. Click the magnet link. When the browser asks to open the app, allow it.
  3. Pick the files you want and a folder, then start the download. On a Mac, copy the link and paste it into the app instead.

What is a magnet link?

A magnet link is a short piece of text that starts with magnet:?. Instead of pointing at a server, it describes the file by its hash — a fingerprint calculated from its contents:

magnet:?xt=urn:btih:40-character hash&dn=ubuntu-24.04-desktop-amd64.iso&tr=udp://tracker.example.org:6969
  • xt=urn:btih:… is the fingerprint. It’s the only required part.
  • dn=… is a display name, so the app can show what you’re about to download.
  • tr=… are trackers: servers that help find other people sharing the file.

A BitTorrent client uses the fingerprint to find peers through those trackers and the DHT (a shared address book of peers), downloads the list of files from them, and then the files themselves — piece by piece, with each piece checked against the fingerprint. That check means you get exactly the file the link describes, or nothing.

A .torrent file carries the same information plus the file list, so the client can show the files straight away. A magnet link has to fetch that list from peers first.

Open magnet links on Windows

  1. Install Prism

    Download the Windows installer and run it. The installer (and the MSI) registers Prism as the app for magnet: links and .torrent files.

  2. Click the magnet link

    Chrome, Edge and Firefox ask whether to open the link in Prism. Tick Always allow if you’ll do this often, then click Open.

  3. Choose the files

    Prism reads the torrent’s file list and lets you untick anything you don’t need — no point in downloading three languages of subtitles if you want one.

  4. Download

    Pick the folder and start. The torrent shows up in the same list as your other downloads and resumes after a restart.

Already have another torrent app set as the default? See how to change the default app below.

Open magnet links on a Mac

  1. Install Prism for Mac.
  2. Right-click the magnet link in your browser and choose Copy Link.
  3. In Prism, click Add URL and paste the link. Prism recognises it as a torrent and lets you choose the files next.

Clicking magnet links directly on a Mac opens whichever torrent app is registered for them; Prism doesn’t register itself for that on macOS, so copy and paste is the way for now.

Open magnet links on Linux

The .deb and .rpm packages of Prism for Linux register it for magnet: links, so clicking one in the browser opens Prism, just as on Windows. With the AppImage, or if another app took over the links, copy the link and paste it into Prism with Add URL (Ctrl+N), or choose Prism for magnet links in your desktop’s Default Applications settings.

Nothing happens when I click a magnet link

The browser doesn’t know which app should open it — either none is installed, or you once chose “don’t open”.

  • Windows 11: Settings → Apps → Default apps → scroll down to Choose defaults by link type → find MAGNET and pick your torrent app.
  • Windows 10: Settings → Apps → Default apps → Choose default apps by protocol → MAGNET.
  • In the browser: if you blocked the prompt earlier, open the site’s settings (the icon left of the address) and reset its permissions, or just copy the link and paste it into the app.

Stuck on “fetching metadata” or 0 peers

A magnet link only contains the fingerprint, so the client first has to find someone who has the file. If nobody is sharing it right now, it waits — forever, if the torrent is dead.

  • Check the seed count on the page where you found the link. Zero or very few seeds means it may never start.
  • Check the firewall. If a security suite or a work network blocks peer-to-peer traffic, the client can’t reach anyone.
  • Try without the VPN, or with a VPN server that allows peer-to-peer traffic.
  • Use the .torrent file if the site offers one; it includes the file list, so at least that step is skipped.

Is it legal and safe?

BitTorrent and magnet links are just a way to share files — Linux distributions, the Internet Archive, game updates and open datasets all use them. What matters is the content: download only what you have the right to, such as free software, public-domain works and files shared with permission.

As for safety, the fingerprint guarantees you get exactly the file the link describes, but not that the file is harmless. Get links from the official source (for example a distribution’s own download page), and scan executables before you run them.

FAQ

Magnet links, answered.

How do I download a magnet link?

Install a BitTorrent client such as Prism or qBittorrent, click the magnet link and allow the browser to open it in the app, then choose the files and a folder. If clicking does nothing, copy the link and paste it into the app (in Prism: Add URL).

Can I download magnet links without uTorrent?

Yes. Any BitTorrent client opens magnet links. Prism and qBittorrent are free, open source and have no ads; Prism also handles ordinary downloads, videos and browser downloads in the same app.

What app opens magnet links?

Whichever BitTorrent client is set as the default for the MAGNET link type. On Windows you can change it under Settings → Apps → Default apps → Choose defaults by link type.

Why is my magnet link stuck on fetching metadata?

The client hasn’t found anyone sharing the file yet. Check that the torrent has seeds, make sure no firewall blocks peer-to-peer traffic, try without a VPN, or use the .torrent file instead of the magnet link.

What is the difference between a magnet link and a torrent file?

Both identify the same download. A .torrent file is a small file that already contains the list of files; a magnet link is just text with the fingerprint, and the client fetches the file list from other peers first.

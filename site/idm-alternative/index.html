Switching from IDM

A free, open-source alternative to Internet Download Manager

If you come from IDM, Prism will feel familiar: click a link and a download window appears, files come down over many connections, videos get a download button, and queues run at night. Prism does it for free — no trial, no license key — on Windows, macOS and Linux, with all of its code in the open.

How to switch

From IDM to Prism in three steps.

You can keep IDM installed while you try Prism — just don’t let both browser extensions run at once.

Step by step

  1. Install Prism

    Pick your system below, or see the guide for Windows, macOS or Linux.

  2. Turn off the IDM Integration Module

    On your browser’s extensions page (chrome://extensions, edge://extensions, …). Two extensions competing for the same download means neither works reliably.

  3. Add Prism’s extension

    From the Chrome Web Store (Firefox: extension guide). Then pick which file types Prism takes in Settings → File types.

FAQ

Questions from IDM users.

Prism isn’t affiliated with Internet Download Manager or Tonec Inc.

Is Prism a free alternative to IDM?

Yes. Prism is free and open source under the MIT license — no trial, no license key, no paid tier and no ads — and it covers the everyday IDM workflows: multi-connection downloads, a browser download window, video grabbing, categories, queues with schedules, a site grabber and a speed limiter.

Is Prism faster than IDM?

We don’t know, so we don’t claim it: IDM hasn’t been measured, because the trial on the test machine had expired and we didn’t bypass it. Against aria2c and curl, Prism matched aria2c on a server that throttles each connection, was 3.2× faster than aria2c without limits, and was the only one to finish on a server that kept dropping connections. The harness is in the repository if you’d like to measure IDM the same way.

Can I use Prism and IDM on the same computer?

Yes. Just keep only one of the two browser extensions turned on, so they don’t both try to catch the same download.

Does Prism download videos like IDM?

Yes. Hover a video and a Download video button appears; pick MP4 in the quality you want or just the MP3. It works on every site yt-dlp supports — more than a thousand. Only download content you have the right to.

Is there an IDM alternative for Mac and Linux?

Prism runs on macOS 11 or later (Apple Silicon and Intel) and on 64-bit Linux (deb, rpm or AppImage), with the same engine and browser extension as on Windows.

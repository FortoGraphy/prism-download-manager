Features

Everything a power downloader expects.
None of the baggage.

Multi-connection engine

Every connection busy until the very last byte.

Prism splits a file into segments and keeps them all moving. The moment a connection finishes, it takes over half of the largest range still left — so nothing sits idle. Servers that limit connections are detected and respected, and a stalled tail gets raced.

  • Up to 32 connections per file, with per-host memory and polite back-off.
  • Writes straight into the final file — no slow “assembling” copy at the end.
  • Crash-safe resume: data is flushed to disk before progress is saved, and checked with ETag / Last-Modified when you resume.
  • HTTP/1.1, HTTP/2, FTP/FTPS, HLS and DASH streams.

Browser integration

Every click, captured.

Click a download link and Prism’s window is already there — in about a quarter of a second, with the file name, size and resume support known. Hold Alt to let the browser handle it instead.

  • Rules by file type, MIME and size decide what Prism takes.
  • Right-click: Download with Prism, or grab all links, images or videos on a page.
  • Logged-in downloads keep working — cookies go only to the app on your own computer.

Verify your download

Every release ships SHA256SUMS.txt. Compare it with the hash of your file:

# Windows (PowerShell)
Get-FileHash .\Prism_*_x64-setup.exe
# macOS
shasum -a 256 Prism_*.dmg
# Linux
sha256sum -c SHA256SUMS.txt --ignore-missing

Prefer to build it yourself? See BUILD.md (Windows & Linux) and BUILD_MACOS.md. All releases are on GitHub Releases.

Guide

Up and running in two minutes.

Install the app, add the browser extension, and you’re done. Pick your system below.

Part 1

Install the app

  1. Run Prism_<version>_x64-setup.exe

    It installs for your user account — no administrator rights needed. (IT admins: use the MSI for all users.)

  2. If SmartScreen appears, click More info → Run anyway

    The installer isn’t signed with a paid certificate, so Windows asks once. The source and the build pipeline are public.

  3. Prism opens with a short welcome tour

    It lives in the system tray while it works. The installer also registers the browser helper, magnet: links and .torrent files.

  4. Now add the browser extension

    Continue with Part 2 — that’s what lets Prism catch downloads.

If something’s off

Troubleshooting

Prism → Settings → Browser integration shows the status of every browser and repairs it with one click.

The popup says “Not connected”

Start Prism (it lives in the tray), then click Retry in the popup. Still failing? Prism → Settings → Browser integration → Repair, then restart the browser.

Downloads still go to the browser

Make sure Capture downloads is on in the popup, and that the file type is in Settings → File types (images aren’t captured by default). blob: downloads from some web apps can’t be handed over.

No “Download video” button

Hover the video. Check Show video button in the extension options, and reload the page after installing the extension.

“Extension ID” mismatch

You loaded a modified copy. Use the official zip — its ID is mmcdeiglkbfbicdjboocmhehodogilfl.

Flatpak or Snap browsers on Linux

Flatpak browsers can’t run native helpers — a browser limitation. Snap Firefox asks for permission once. For full integration use a browser installed from a deb or rpm package.

What does the extension send, and where?

A download’s address, the page it came from, the browser’s user agent and that site’s cookies — only to the Prism app on your own computer, through native messaging. No network, no servers, no analytics.

FAQ

Questions, answered.

Something else? Ask in Discussions or open an issue.

Is Prism really free?

Yes. Prism is open source under the MIT license — no trial, no paid tier, no ads, no account. Bundled or downloaded components (yt-dlp, ffmpeg and others) keep their own licenses.

Is it safe to install?

Every line of code is public, and release builds are produced by GitHub Actions from that source. Each release lists SHA-256 checksums so you can verify your file. Prism collects no telemetry, and its browser extension only talks to the app on your own computer.

Windows SmartScreen and macOS Gatekeeper may warn on first run simply because the builds aren’t signed with paid certificates yet — see the guide.

Does it work like IDM?

For the workflows people love IDM for — yes: dynamic multi-connection downloads, a browser “download this” window, video grabbing, categories, queues with schedules, a site grabber, a speed limiter and batch downloads. Prism is a clean-room implementation and isn’t affiliated with Internet Download Manager. We haven’t benchmarked IDM yet (see Benchmarks).

Does it work with Firefox?

Yes — the extension supports Firefox as well as Chrome, Edge, Brave, Opera, Vivaldi and Chromium. The extension isn’t signed by Mozilla, so regular Firefox keeps it until restart; Developer Edition, Nightly and ESR can keep it permanently. How to install it.

Is there a Flatpak? What about Snap browsers?

Prism ships as deb, rpm and AppImage. There’s no Flatpak yet: browser integration relies on a native helper, which a sandboxed app can’t register without extra work. Flatpak browsers can’t start native helpers at all, so for full integration use a browser from a deb/rpm package; Snap Firefox works after a one-time permission prompt.

Why does macOS say the app can’t be opened?

The macOS build isn’t notarized by Apple yet, so macOS blocks it the first time (it may also close it after a few seconds). Allow it once with System Settings → Privacy & Security → Open Anyway, or clear the quarantine flag in Terminal. Updates installed from inside Prism don’t need this again.

xattr -dr com.apple.quarantine /Applications/Prism.app
Which sites can it download videos from?

Every site yt-dlp supports — more than a thousand, including YouTube, Vimeo, Twitch, X, Instagram, TikTok, Reddit and SoundCloud. Prism installs yt-dlp, ffmpeg and deno for you, verifies them by SHA-256 and keeps yt-dlp updated. Only download content you have the right to.

How can I help?

Star the repo and tell a friend — it genuinely helps. Bug reports, translations, docs and pull requests are all welcome; start with CONTRIBUTING.md. Have a licensed IDM? Running the benchmark harness and sharing the numbers would be great.

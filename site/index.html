Features

Everything a power downloader expects.
None of the baggage.

Multi-connection engine

Every connection busy until the very last byte.

Prism splits a file into segments and keeps them all moving. The moment a connection finishes, it takes over half of the largest range still left — so nothing sits idle. Servers that limit connections are detected and respected, and a stalled tail gets raced.

  • Up to 32 connections per file, with per-host memory and polite back-off.
  • Writes straight into the final file — no slow “assembling” copy at the end.
  • Crash-safe resume: data is flushed to disk before progress is saved, and checked with ETag / Last-Modified when you resume.
  • HTTP/1.1, HTTP/2, FTP/FTPS, HLS and DASH streams.

AI models · new in 1.1.7

Hugging Face models. Just the files you need.

Type a model’s name, paste its link or search. Prism picks the right files — one GGUF version (Q4_K_M unless you choose another), or the weights in one format with the configs and tokenizer beside them — downloads each over many connections and checks it against the SHA-256 Hugging Face lists.

  • Gated and private models with your access token, which goes only to Hugging Face.
  • Save straight into LM Studio’s models folder, or anywhere you like.
  • Mirrors such as hf-mirror.com work too; files you already have are skipped.

If something’s off

Troubleshooting

Prism → Settings → Browser integration shows the status of every browser and repairs it with one click.

The popup says “Not connected”

Start Prism (it lives in the tray), then click Retry in the popup. Still failing? Prism → Settings → Browser integration → Repair, then restart the browser.

Downloads still go to the browser

Make sure Capture downloads is on in the popup, and that the file type is in Settings → File types (images aren’t captured by default). blob: downloads from some web apps can’t be handed over.

No “Download video” button

Hover the video. Check Show video button in the extension options, and reload the page after installing the extension.

The store says Prism is already added

That’s the copy you added by hand with an older Prism. Remove it on the browser’s extensions page (chrome://extensions, edge://extensions, …), then add Prism from the Chrome Web Store: the store version updates by itself.

“Extension ID” mismatch

You loaded a modified copy. Use the Chrome Web Store version — its ID is mmcdeiglkbfbicdjboocmhehodogilfl.

Flatpak or Snap browsers on Linux

Flatpak browsers can’t run native helpers — a browser limitation. Snap Firefox asks for permission once. For full integration use a browser installed from a deb or rpm package.

What does the extension send, and where?

A download’s address, the page it came from, the browser’s user agent and that site’s cookies — only to the Prism app on your own computer, through native messaging. No network, no servers, no analytics.

FAQ

Questions, answered.

Something else? Ask in Discussions or open an issue.

Is Prism really free?

Yes. Prism is a free, open-source download manager under the MIT license — no trial, no paid tier, no ads, no account. Bundled or downloaded components (yt-dlp, ffmpeg and others) keep their own licenses.

Is it safe to install?

Every line of code is public, and release builds are produced by GitHub Actions from that source. Each release lists SHA-256 checksums so you can verify your file. Prism collects no telemetry, and its browser extension only talks to the app on your own computer.

Windows SmartScreen and macOS Gatekeeper may warn on first run simply because the builds aren’t signed with paid certificates yet — see the guide.

Is Prism an alternative to IDM (Internet Download Manager)?

For the workflows people use IDM for — yes: dynamic multi-connection downloads, a browser “download this” window, video grabbing, categories, queues with schedules, a site grabber, a speed limiter and batch downloads. Prism is free, open source and runs on Windows, macOS and Linux. It’s a clean-room implementation and isn’t affiliated with Internet Download Manager, and we haven’t benchmarked IDM yet (see Benchmarks). More in Prism as an IDM alternative.

Does Prism make downloads faster?

Often, yes. Many servers and mirrors limit the speed of each connection. Prism works as a download accelerator: it splits a file across several connections (8 by default, up to 32), so in our test a 1 GiB file from such a server finished 15× faster than over a single connection.

When a server doesn’t limit connections, a good downloader simply fills your line, and nothing beats the line itself: on a real ≈ 200 Mbit/s connection Prism, aria2c and curl all finished at the same speed. The benchmarks show both cases.

Can it resume broken or interrupted downloads?

Yes. Pause, close the laptop, lose the connection or the power: Prism writes data to disk before it saves its progress, so it continues from the last byte it safely wrote. On resume it checks the file’s size, ETag and Last-Modified with the server, so a file that changed in the meantime is never stitched together from two versions. The Download window shows whether a server supports resuming before you start.

Which sites can it download videos from?

Every site yt-dlp supports — more than a thousand, including YouTube, Vimeo, Twitch, X, Instagram, TikTok, Reddit and SoundCloud. Pick MP4 in the quality you want (up to 8K HDR) or just the MP3, with subtitles, chapters and SponsorBlock. Prism installs yt-dlp, ffmpeg and deno for you, verifies them by SHA-256 and keeps yt-dlp updated. Only download content you have the right to.

Does Prism download torrents and magnet links?

Yes. Prism opens magnet: links and .torrent files in its own torrent window: pick the files you want, the folder, the category and the queue, and see the free space before you start. A torrent with several files gets a folder of its own.

Can it download AI models from Hugging Face?

Yes, since 1.1.7. Click the model button in the toolbar, or paste a model’s name like Qwen/Qwen3-8B or its link into Add URL. Prism picks the files you need — for GGUF models one quantization, Q4_K_M unless you choose another — downloads them over many connections and checks each against its SHA-256. Gated and private models work with an access token. How it works.

Which browsers does the extension work with?

Chrome, Edge, Brave, Opera, Vivaldi and Helium add it from the Chrome Web Store, Firefox and Zen from Firefox Add-ons: one click, and the store keeps it up to date. How to install it · more about the extension.

Which systems and languages does Prism support?

Windows 10 and 11 (64-bit), macOS 11 Big Sur or later on Apple Silicon and Intel, and 64-bit Linux as a deb, rpm or AppImage. The app speaks English, Czech, German, Spanish, French, Italian, Indonesian, Turkish, Simplified Chinese and Arabic, and follows your system’s language.

Is there a Flatpak? What about Snap browsers?

Prism ships as deb, rpm and AppImage. There’s no Flatpak yet: browser integration relies on a native helper, which a sandboxed app can’t register without extra work. Flatpak browsers can’t start native helpers at all, so for full integration use a browser from a deb/rpm package; Snap Firefox works after a one-time permission prompt.

Why does macOS say the app can’t be opened?

The macOS build isn’t notarized by Apple yet, so macOS blocks it the first time (it may also close it after a few seconds). Allow it once with System Settings → Privacy & Security → Open Anyway, or clear the quarantine flag in Terminal. Updates installed from inside Prism don’t need this again.

xattr -dr com.apple.quarantine /Applications/Prism.app
